Publicar una web con GitHub Pages

Del primer repositorio a una web publicada, sin salir del navegador.

Una página web puede empezar con algo tan sencillo como un archivo index.html. GitHub guarda los archivos y su historial; GitHub Pages los convierte en una web que puedes visitar y compartir.

La guía, paso a paso

La guía de GitHub Pages recorre todo el proceso, desde preparar la cuenta hasta comprobar los cambios publicados:

  • Crear un repositorio para guardar la web.
  • Subir el HTML y los archivos de estilos e imágenes.
  • Activar GitHub Pages en la configuración.
  • Visitar la web y publicar actualizaciones.

Incluye un ejemplo descargable, una lista para seguir el progreso y respuestas a los problemas más habituales.
